Layer 5 of the OSI Model

Defintion

Layer 5 is the session layer, manages and setups connections between different systems. Helps with reliable connection that is organized and efficient. This layer is in between layer 7 and 6, an is crucial for allowing systems to communicate with each other.



Functions

Layer 5 uses functions like session setup, which first creates a connection between two systems or application, usually with setting parameters and authentication when needed. Synchronization, set up checkpoints for recovery in case of session failure. Termination, ending a session and ensuring all data is properly exchanged and none is lost.


Function Overview
  • Session setup - communication parameters, authentication, duplex mode
  • Maintenance - checkpoints, prevents duplication, Controls turn, security
  • Termination - ends communication
  • Synchronization - recover from failures (synchronization points). Avoid overlapping


Protocols

Layer 5 has protocols like ADSP, which was developed by Apple and allows a network to configure itself for reliable data delivery. RTCP, which ensures the quality of the data remains high, by providing feedback regarding the quality of a data stream. PAP, used for security by limiting access to users and asking for a password request.


Protocol Overview
  • ADSP (AppleTalk Data Stream Protocol) - developed by Apple Inc. allows a network to configure itself.
  • RTCP (real-time transport control protocol) - make sures the quality of service remains high.
  • PAP (password authentication protocol) - limits access to users to ensure security. Asks for password request.


Coordinate Ongoing Exchange

Layer 5 coordinates ongoing exchanges by allowing systems to send data to each other smoothly and securely. On an active video call layer 5 will establish a connection between the two and use checkpoints incase the call experiences an error.



Relationship to Other OSI Layers

Layer 6, the presentation layer formats and encrypts data that is sent over a session created by layer 5 and the other layer 6 decrypts once it reached its destination.

Layer 4, the transport layer uses the session created by layer 5 to transport the data effectively.
