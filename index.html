Layer 6 of the OSI Model

Definition

Layer 6, the presentation layer, is also known as the syntax layer or translation layer. It has the role of transmitting encrypted formatted data across networks and ensuring it’s readable by other systems. It receives data from layer 7 and formats it to be transmitted over the network. Main functions involve providing the proper data format and encryption.



Functions

Layer 6 functions with data translation, which translates data into another format to be read by other systems. Encryption/decryption translates the data into an unreadable format known as ciphertext before it is transmitted, and decrypts it after reaching the receiver. Compress/decompression encodes the data to increase the speed at which it is being transmitted. The receiver then decompresses it to access the information.


Quick Summary
  • Data translation - translates data into another format to be used by another system, and translates it back later.
  • Encryption/Decryption - Encrypts the data into an unreadable format, known as ciphertext, before transmission. The receiver has the correct encryption key to access the data.
  • Compression/Decompression - Compresses the data to increase the speed at which it can be transmitted. (ZIP, MPEG, etc.) Decompresses at the receiver end to access the information.


Format Examples

Examples of formats are things like JPEG, which is used for compressing images. MP3, which is used for compressing audio, and SSL or TLS, which encrypts data as it's being transmitted to prevent interceptions of the data.


Simplified List
  • JPEG (Joint Photographic Experts Group) - a format for compressing images.
  • MP3 (MPEG (Motion Picture Experts Group) Layer 3) - a format for compressing audio files.
  • ASCII (American Standard Code for Information Interchange) - translates letters, symbols, and numbers into numerical values for computers to understand.
  • SSL (Secure Sockets Layer) - Encrypts data that is being transmitted to prevent interceptions.
  • TLS (Transport Layer Security) - Evolved from SSL, encrypts communication between web applications and servers.


Compatability

Different systems may use different encoding systems which are not compatible with each other at first. Layer 6 ensures compatibility by translating the data into the proper syntax that the other system understands. This way, the other system can accurately communicate with a different system without a huge error.



Relationship to Other OSI Layers

Layer 6 formats and encrypts the data sent by the application layer to ensure that the other system’s application layer can understand. This way, the application layer of a different device can send emails and access the same web pages from an entirely different type of system or device.

Layer 6 interacts with other layers as well. For example, with Layer 5, the session layer, layer 5 helps two different systems connects with each other. Layer 6 is able to encrypt data which layer 5 can help transmit by creating a session between two systems.
