Layer 4 of the OSI Model

Defintion

Layer 4 is the transport layer it has the role of data transfer between two systems. This layer sits between layer 5 and layer 3 and is needed to transport data across a network both effectively and securely.



Functions

Layer 4 uses functions like segmentation, breaking down the data for faster and more efficient data transfer. Reassembly, to put the data back together at its destination to be properly read. Flow control, manages the rate of data transmission to prevent overloading on slower recievers.


Function Overview
  • Segmentation - breaks down data for network transmission
  • Reassembly - reconstructs the data into its original format at the destination
  • Error checking - checksums are used to verify data integrity. Compares incoming and transmitted values and data to find corruption
  • Flow control - manages the rate of data transmission from fast senders to slow receivers, this prevents overloading


Protocols

Layer 4 uses protocols like TCP, a reliable protocol that requires a connection to be set up before data is transmitted. UDP, doesn’t require a connection and priotizes speed and size over security and overall reliability. SCTP, a reliable transport protocol that has both features of TCP and UDP.


Protocol Overview
  • TCP (Transmission Control Protocol) - typically a reliable protocol, connection oriented (connection is created first before data is transferred, and terminated once data transmission ends)
  • UDP (User Datagram Protocol) - a connentionless protocol, used when speed and size is more important than security and reliability (data is just given an address, checksums, and length information
  • SCTP (Stream Control Transmission Protocol) - most commonly used, dependable transport protocol that has features of both UPD and TCP.


Real World Examples

TCP is used in web browsings to ensure that everything properly loads with it’s reliable delivery. UPD is used in videos, online games, and live videos because it prioritizes aspects of data transfer like its speed and size over a need for everything to load perfectly and securely as possible.



Relationship to Other OSI Layers

Layer 5 sends data to layer 4 to be broken into segments before transmitted along one of layer 5’s sessions.

Layer 3, the network layer, receives the data from layer 4 and adds IP address before routing it to the correct location for transmission.
